# ПОПУТНО — Дневник настроения

Веб-приложение для анализа эмоционального состояния на базе DeepSeek LLM.
Кросс-культурный анализ, локальное хранение истории, режим «нулевого сохранения» на сервере.

## Возможности

- 📔 Дневник настроения с AI-анализом через DeepSeek API
- 🧠 Оценка психического здоровья (0–100), эмоция, триггеры, анализ, рекомендация
- 🌍 Поддержка смешанных языков (русский / китайский и др.)
- ✈️ Планирование поездок
- 📊 Визуализация истории настроения (Chart.js)
- 🎤 Голосовой ввод (Web Speech API)
- 🔒 Приватность: история хранится локально в `localStorage`, сервер не пишет данные на диск

## Стек

- **Backend:** Python 3, Flask, Flask-CORS, requests, python-dotenv
- **Frontend:** HTML, CSS, JavaScript, Chart.js
- **AI:** DeepSeek Chat API
